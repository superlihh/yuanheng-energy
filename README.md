# 源衡智控——基于云边协同的工业企业源网荷储智能优化与AI辅助决策平台

面向华为 ICT 创新赛道的工业能源数字化原型，主要解决企业生产任务、电价、负荷、储能和并网约束无法统一分析的问题。系统以“端边云能源数据采集—多时间粒度分析—生产约束建模—源网荷储优化—AI解释—人工审核—结果复盘”为主线，默认演示为制造业流水线。

产品名称为“源衡智控”。原有 PowerPilot 目录和接口名称保留，以兼容已有启动脚本、测试和部署方式；页面、AI提示词和竞赛文档统一使用源衡智控表达。

实际架构：Java 21 认证网关和静态资源服务 + Python 数据、业务与优化服务 + SQLite + HTML/CSS/JavaScript。Java 转发业务请求，Python 再校验企业权限、状态与计算输入；当前没有把审批业务迁移成 Spring Boot 服务。

当前主工作台采用 `C:\Users\12237\Documents\Qoder\2026-10-23\3f6e6fbf` 提供的源衡界面，落地文件为 `frontend/index.html`、`frontend/css/style.css` 和 `frontend/js/`。`frontend/js/live.js` 是后端适配层，负责登录注册、企业数据同步、方案审核、预警处置、CSV 导入、报告导出和 AI 问答；界面中的预测、模拟成本和正式账单仍按不同口径显示。

项目词典位于 `config/sourceheng_dictionary.json`；竞赛展示流程见 `docs/源衡智控竞赛展示方案.md`，接口和测试问题见 `docs/源衡智控接口与测试清单.md`。

## 完整演示顺序

1. 注册企业账号，进入“设备与产线”，先在“企业与生产约束”中确认企业名称、计量点、购电口径、并网功率和生产窗口；真实试点不要把演示参数当成正式规则。
2. 在“设备与产线”登记智能电表、PLC 状态点或储能 BMS；空空间可以载入5台明确标识的合成设备，查看只读遥测、质量码和设备批次。真实设备需使用企业确认的网关和只读权限。
3. 进入“数据与账单”，在“本次导入元信息”中填写来源、计量点、授权范围和粒度，再使用“载入21天演示”体验完整流程；真实企业改用“导入数据”，不要把演示样本和真实数据混在一个空间。
4. 在“调度总览”确认企业、计量点、规划日和当前冻结批次；在“价格预测”检查小时价格、负荷、储能 SOC 和数据性质。
5. 在“五方案比较”查看 S0 原计划、S1 固定合同、S2 移峰、S3 储能和 S4 组合方案。只有状态为可行且输入数据完整的方案才能提交后端草案。
6. 在“时序排程”检查生产动作、充放电和并网余量；预测为空时系统只显示待补齐状态，不把公开日级价格复制成企业分时预测。
7. 在“长期规划”查看合同覆盖率、现货敞口和月度预算情景；这些结果是独立规划参考，不自动改写日内调度方案。
8. 在“预警中心”确认、分派、处理或忽略可处置预警。阻断预警不能靠忽略绕过审核；每次处置都会写入审计记录。
9. 在“策略解释”向 AI 问当前方案的问题。AI 回答会绑定方案、批次、字段和计算证据；未接入外部模型时会明确使用本地规则解释。
10. 在首页“当前决策闭环”按 NEXT ACTION 推进；它会把缺数据、账单复核、方案保存、风险处置、审核、执行登记和结果复盘串成一条可追踪路径。
11. 在“版本审核”先提交方案，再由独立批准人审核。审核页的“团队角色”区域可生成批准人、财务、生产负责人或设备负责人的邀请码，另一账号加入企业空间后会自动刷新权限。
12. 批准后必须在同页登记实际执行电量和计量来源；服务端只允许当天批准版本、输入指纹未变化且无阻断预警的方案登记执行。
13. 执行登记不会直接生成节省金额。执行后打开“数据与账单 → 账单核对”，填写实际计量来源、反事实基准和 24 小时实际曲线 CSV，由财务或其他授权人员提交核验，报告才会记录 actualSaving。
14. 点击“导出决策报告”下载当前企业的 JSON 报告；报告区分模拟差额、正式账单差异和实际节省，不能把预测结果当作收益承诺。
15. 设备台账、团队权限、正式执行登记和实际节省核验仍由现有 API 与后台模块提供，现场接入通过只读网关完成；AI 不下发控制指令，系统不自动申报交易。

## 生产线能力

- 最多8道固定批次、整小时连续工序，支持多产线分组、订单号、设备编号和固定任务量。
- 前置工序必须完成后才能开始后续工序；同一设备编号禁止同时被两个任务占用。
- 每道工序有原计划、允许时间窗口、连续时长、功率和禁运行小时。班次、检修等可通过窗口及禁运行小时表达。
- 保持所有已录入任务、连续时长和工序电量，原始总负荷应已包含原计划工序；基础负荷不会凭空减少。
- 一套储能：SOC、功率、充放电互斥、效率、循环限制、停用时段、寿命与日运维费用。
- 并网功率上限与禁止反送电为硬约束；没有可行解时不输出可执行方案。

任务量是本次固定标签，不是完整产能方程。跨日排产、在制品流转、变速产线、爬坡、最小开停机时长、启停成本、多套储能、多站点仍需专项建模。

## 数据导入

支持 CSV、第一工作表 XLSX、JSON 记录数组；统一列名：

```csv
timestamp,price_yuan_mwh,load_kw,temperature_c,renewable_kw,contract_kwh,contract_price_yuan_mwh
2026-10-21T00:00,260,520,16,0,300,350
2026-10-21T01:00,240,500,15,0,300,350
```

前三列必填；合同电量与价格成对填写；允许负电价。时间为北京时间区间起点；带时区的时间转换为北京时间。价格与功率等字段必须是数值，不能含单位文本。Excel 公式单元格会被拒绝，需先导出为值。单文件最大1.8MB，最多10000条记录。

导入时选择60分钟或15分钟。15分钟数据必须每小时四段齐全，先守恒聚合到小时；不完整批次隔离。原始文件、SHA256、来源、计量点、授权说明和标准化摘要保留，可下载。完整日必须包含00—23时；缺失值不补零。错误记录导致整批拒绝；文件格式本身无法解析时返回错误，尚不形成批次。

公开的日级市场样本只用于参考看板，不能替代企业分时价格、负荷或结算依据。15分钟聚合的合同价格可能是保留原区间费用的**小时等效价**，详见设计文档。

## 计算与版本

预测比较上一完整日、近7日同小时均值、时序岭回归及有足够气象/新能源数据时的多源岭回归。满14个完整日后分开方法选择期与独立测试期，报告价格 MAE、RMSE、高价小时误差和负荷 MAE。未来气象未接入时只用已知滞后特征；经验误差带不是概率保证。

调度使用 SciPy `milp` / HiGHS 联合求解。五类场景独立计算，共用 S0 基准；组合差额不能把单项差额相加。S1 为已有固定合同分析，**合同交易量未优化**。无储能显示“不适用”，缺少相关字段显示“数据不足”。

费用支持全电量参考分析、固定合同差额分析。寿命折损与已安装储能日运维计入相应场景。未适配的输配电、基本/需量、税费与正式调整明确列出，不据此声称完整账单节省。基准储能目前设为空闲；已有运行中的储能基准计划需进一步接入。

方案冻结数据批次、输入指纹、参数和模型版本。修改另存父子版本，保留人员、原因、差异与审核记录。参数或新数据变化使旧版本失效。压力测试区分固定动作与重优化，同时扰动 S0 和候选；重优化生成评估子稿，采纳前须确认正式输入并重算审核。

预警提供四级、去重、责任人分派、状态流转及内部审计。阻断预警无法通过“忽略”绕过审批。当前页面请求时检查预警，无后台全天候采集、邮件/短信推送或现场安全联锁。

## AI 配置

阿里云百炼 Model Studio 的 API Key 只放在服务器环境变量中。CSV 凭证导出文件只用于读取 `openAiCompatible` 地址，不能放进项目目录。完整部署步骤见 `docs/阿里云百炼接入说明.md`。

复制 `.env.example` 为本机或服务器上的 `.env`，只在服务器填写密钥：

```dotenv
AI_API_KEY=仅填写服务器环境变量，不要写入前端
AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_PRIMARY_MODEL=qwen3.7-plus
AI_REASONING_MODEL=qwen3.8-max
AI_AUTO_FALLBACK=false
AI_ALLOW_PAY_AS_YOU_GO=false
AI_STOP_ON_LOCAL_LIMIT=true
AI_STOP_ON_QUOTA_ERROR=true
AI_MAX_RETRIES=0
AI_TIMEOUT=30000
AI_MAX_REQUESTS_PER_USER_PER_DAY=20
AI_MAX_REQUESTS_TOTAL_PER_DAY=100
AI_DAILY_TOKEN_LIMIT=30000
AI_TOTAL_TOKEN_LIMIT=300000
AI_DEEP_ANALYSIS_ENABLED=false
AI_DOCUMENT_KNOWLEDGE_BASE_ENABLED=false
AI_COST_PROTECTION_ENABLED=true
```

重启后生效。若使用 Model Studio 为工作空间生成的兼容地址，将 `AI_BASE_URL` 改为该工作空间的 `compatible-mode/v1` 地址。前端只请求 `/api/ai/chat`，密钥只由 Python 服务读取，不会返回给 Java 网关或浏览器。系统不自动切换模型、不自动重试；达到本地请求或 Token 限制、模型限流、余额或额度错误时停止调用并记录原因。`GET /api/ai/usage` 仅管理员可查看每日调用次数、Token、模型和错误状态。

未连接模型、模型超时、限流或返回格式错误时，`/api/ai/chat` 会返回明确标注的本地规则解释，并保留数据来源、置信度和人工复核要求；达到本地安全上限时会阻断调用并说明原因，不会用猜测内容冒充真实数据。AI 只能使用后端白名单数据函数，所有高风险建议需要人工确认。

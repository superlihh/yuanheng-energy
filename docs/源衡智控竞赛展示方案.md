# 源衡智控竞赛展示方案

## 项目定位

源衡智控是面向工业企业的云边协同源网荷储智能优化与 AI 辅助决策平台。系统把智能电表、PLC、SCADA、MES、储能 BMS/PCS 和人工导入数据统一到企业授权空间，按实时、15 分钟、小时、日、周、月、季度和年度粒度分析生产用能，再将电价、生产任务、储能 SOC、并网容量和禁止反送电等约束放入同一优化模型。

系统的核心价值不是做一个能源大屏，也不是让模型直接控制设备，而是形成可追溯的决策闭环：

`端侧采集 → 边缘清洗与缓存 → 云端数据治理 → 多粒度分析 → 负荷预测 → 生产约束建模 → 源网荷储优化 → AI解释 → 人工审核 → 执行登记 → 结果复盘`

## 华为 ICT 创新赛道表达

演示时可将技术路线表达为“端边云一体化、国产化可迁移”。端侧使用智能电表、PLC、BMS、PCS 和传感器，边缘侧通过 Modbus、OPC UA、MQTT 或 HTTP 网关完成只读采集、质量校验、时间同步、本地缓存和断网续传，云侧负责时序数据、关系数据、模型推理、优化计算、权限和审计。

竞赛部署可映射到华为云 IoTDA、OBS、ModelArts、MindSpore、GaussDB/openGauss、CCE、FunctionGraph、IAM、云监控和云日志。当前项目是可运行原型，现场演示使用本地 Java/Python/SQLite；云服务映射属于可迁移部署方案，不能描述为已经完成真实云上接入。

## 现场演示流程

1. 登录源衡智控，展示企业空间和角色权限。
2. 在设备与产线登记智能电表、生产线、储能和只读边缘网关。
3. 导入一份带来源、计量点、时间粒度和授权说明的企业用能数据。
4. 查看数据质量、实时负荷、价格、能源结构和储能 SOC。
5. 查看生产任务的工序窗口、设备互斥、并网功率和禁止反送电约束。
6. 运行 S0 原计划、S2 移峰、S3 储能、S4 联合优化，展示优化前后成本、峰值负荷、峰谷差、储能动作和约束校验。
7. 询问“如果明日电价上涨15%，如何安排生产任务和储能？”，展示 AI 调用受控数据工具后的结构化回答。
8. 展示 AI 回答中的数据来源、更新时间、统计粒度、数据质量、置信度和不能确定的内容。
9. 将建议提交为人工审核提案，由审核角色确认后再进入方案审核；AI 不直接控制设备。
10. 登记执行结果，使用实际计量和正式账单进行结果复盘，区分模拟差额和实际节省。

## 可复现指标

每次优化必须固定规划日、输入批次、预测版本、企业参数版本、费用口径和输入指纹。现场至少展示：

- 优化前后成本和模拟差额；
- 最大并网功率和峰谷差；
- 生产任务完成量和工序开始时间；
- 储能充电量、放电量、SOC 起止值和循环约束；
- 并网功率上限、禁止反送电和设备健康检查；
- 预测与实际偏差；
- 数据完整性、异常记录和告警闭环状态。

## AI回答口径

AI 只通过后端白名单工具读取授权数据，回答采用 `intent、scope、facts、comparisons、metrics、analysis、risks、suggestions、dataQuality、sources、confidence、needHumanReview` 结构。客观事实、系统计算、AI判断、可能性推测和辅助建议分层显示。

当区域、生产、天气、检修或储能数据没有接入时，回答必须明确“当前数据不足”，不能用地图演示拓扑或模拟数据冒充企业真实数据。

## 当前原型边界

- 真实 SCADA、MES、BMS、OPC UA、MQTT 和 Modbus 适配需要按企业点表验收。
- 地图和线路目前属于演示拓扑，不能当作实时调度拓扑。
- SQLite 适合比赛演示，不等同生产环境的高可用数据库。
- AI 只提供辅助分析和人工审核提案，不执行设备控制、调度、交易申报或自动审批。
- 模拟数据、预测结果和模拟节省必须带有明确标识，正式收益需要实际执行和账单核验。

# 阿里云百炼接入说明

本文只说明配置方法，不保存任何真实 API Key。项目使用后端代理，浏览器只访问本系统的 `/api/ai/chat`，不会直接访问模型服务。

## 1. CSV 的正确用途

从百炼控制台下载的 `默认业务空间-apiKey-*.csv` 是凭证导出文件，包含 API Key、业务空间和兼容接口地址。它不是应用配置文件，不要复制到项目目录、压缩包、截图、日志或 Git。

当前项目只读取服务器进程环境变量。CSV 中的 `openAiCompatible` 字段用于确认 `AI_BASE_URL`，API Key 只复制到服务器的临时环境变量或服务器密钥管理工具中。

用户曾在聊天中粘贴过 API Key，该 Key 应视为已暴露。正式联调前，请在百炼控制台撤销旧 Key 并重新创建一个只用于本系统的服务端 Key。

## 2. 推荐配置

在服务器上配置以下变量。不要把尖括号和值示例一起复制，`AI_BASE_URL` 使用 CSV 的 `openAiCompatible` 字段，模型名称以控制台实际可用模型为准。

```text
AI_API_KEY=<重新生成的服务端密钥>
AI_BASE_URL=<CSV 中的 openAiCompatible 地址>
AI_PRIMARY_MODEL=qwen3.7-plus
AI_REASONING_MODEL=qwen3.8-max
AI_EMBEDDING_MODEL=qwen3.7-text-embedding-flash
AI_RERANK_MODEL=qwen3.7-text-rerank
AI_AUTO_FALLBACK=false
AI_ALLOW_PAY_AS_YOU_GO=false
AI_STOP_ON_LOCAL_LIMIT=true
AI_STOP_ON_QUOTA_ERROR=true
AI_MAX_RETRIES=0
AI_TIMEOUT=30000
AI_MAX_REQUESTS_PER_USER_PER_DAY=20
AI_MAX_REQUESTS_TOTAL_PER_DAY=100
AI_MAX_TOKENS_PER_REQUEST=2000
AI_MAX_INPUT_TOKENS=6000
AI_MAX_OUTPUT_TOKENS=1500
AI_DAILY_TOKEN_LIMIT=30000
AI_TOTAL_TOKEN_LIMIT=300000
AI_DEEP_ANALYSIS_ENABLED=false
AI_DOCUMENT_KNOWLEDGE_BASE_ENABLED=false
AI_COST_PROTECTION_ENABLED=true
AI_BUDGET_WARNING_PERCENT=80
AI_BUDGET_STOP_PERCENT=90
```

也兼容 `DASHSCOPE_API_KEY`、`OPENAI_BASE_URL` 和 `OPENAI_MODEL` 旧变量，但新部署优先使用上面的 `AI_*` 变量。项目不会自动切换模型，也不会自动重试。

## 3. Windows 启动

在 PowerShell 中进入项目目录后设置当前进程变量，再启动服务。关闭窗口后这些变量会失效，适合本地测试；长期运行建议使用 Windows 服务的受保护环境变量。

```powershell
Set-Location 'C:\Users\12237\Desktop\实验'
$env:AI_API_KEY = '<重新生成的服务端密钥>'
$env:AI_BASE_URL = '<CSV 中的 openAiCompatible 地址>'
$env:AI_PRIMARY_MODEL = 'qwen3.7-plus'
$env:AI_REASONING_MODEL = 'qwen3.8-max'
$env:AI_MAX_RETRIES = '0'
$env:AI_AUTO_FALLBACK = 'false'
$env:AI_ALLOW_PAY_AS_YOU_GO = 'false'
$env:AI_STOP_ON_LOCAL_LIMIT = 'true'
$env:AI_STOP_ON_QUOTA_ERROR = 'true'
.\start.ps1 -Restart
```

## 4. Linux 服务器启动

不要把密钥写入项目目录。可以在 systemd 的受保护环境文件中设置，文件权限设为 `600`，并让服务用户读取。临时验证可以在当前 SSH 会话中执行：

```bash
cd /opt/powerpilot
read -s AI_API_KEY
export AI_API_KEY
export AI_BASE_URL='<CSV 中的 openAiCompatible 地址>'
export AI_PRIMARY_MODEL='qwen3.7-plus'
export AI_REASONING_MODEL='qwen3.8-max'
export AI_MAX_RETRIES='0'
export AI_AUTO_FALLBACK='false'
export AI_ALLOW_PAY_AS_YOU_GO='false'
export AI_STOP_ON_LOCAL_LIMIT='true'
export AI_STOP_ON_QUOTA_ERROR='true'
mkdir -p data/logs backend-java/classes
javac -encoding UTF-8 -d backend-java/classes backend-java/src/PowerOptimizerServer.java
nohup .venv/bin/python python-service/service.py > data/logs/python.out.log 2>&1 &
nohup java -cp backend-java/classes PowerOptimizerServer frontend > data/logs/java.out.log 2>&1 &
```

如果使用现有的 `nohup` 启动方式，必须在启动 Python 服务的同一个 shell 中先 `export` 这些变量。项目当前没有 `start.sh`，Linux 服务器按上面的命令启动；服务重启后环境变量没有继承时，健康接口会显示 `ai: false`。

## 5. 验证

先登录系统取得会话令牌，再调用以下接口：

```text
GET  /api/health
GET  /api/ai/usage       # 仅管理员
POST /api/ai/chat
```

`/api/health` 只返回是否已配置、模型名和安全开关，不返回 API Key。普通问答请求示例：

```json
{
  "messages": [
    {"role": "user", "content": "请分析当前企业负荷趋势"}
  ],
  "stream": false
}
```

没有密钥、模型认证失败、模型返回 402/429、网络超时或返回非 JSON 时，问答接口会返回标注为“本地规则”的数据驱动解释，并保留人工复核提示；达到本地请求或 Token 上限时会阻断调用并明确说明原因。系统不会自动切换模型或重试。

## 6. 额度和费用边界

- 百炼的免费额度、节省计划抵扣额度、按量付费和 Token 用量是不同概念，应用本地限制不能读取或改变账户真实余额。
- 本项目的请求次数、Token 上限、深度分析权限、模型白名单和停止阈值只约束当前应用及其使用的 Key。
- 其他程序或其他 API Key 仍可能产生账户费用，因此还需要在百炼控制台设置账户消费预警，并按实际规则配置“用完即停”。
- 项目不能百分之百替代云账户级预算控制；上线前应由管理员在控制台确认节省计划、目标模型和按量付费规则。
- `/api/ai/usage` 可查看当天模型、请求数、输入/输出 Token、成功和阻止原因，便于人工停用。

## 7. 当前未启用的能力

Embedding、Rerank、知识库和深度分析默认关闭。未启用知识库时不会调用向量模型；未明确开启深度分析时不会调用 `qwen3.8-max`。AI 只能读取后端白名单函数提供的授权数据，不能直接访问数据库、修改生产数据或控制设备。

# 开源项目调研与采用方案

更新时间：2026-10-22。本文记录本原型能够借鉴的公开项目、实际采用的部分，以及许可证边界。开源项目是设计参考和候选依赖来源，不表示本系统复制了它们的源码，也不表示已连接所有协议或设备。

## 已落地

### Apache ECharts 5.6.0

系统已将 ECharts 5.6.0 的浏览器发行文件固定放在 `frontend/vendor/echarts-5.6.0/`，用于预测价格/负荷双轴图、排程前后对比、储能 SOC 和设备历史曲线。下载来自 npm 官方包，发布的 SHA-512 完整性值已校验，目录内保留 `LICENSE`、`NOTICE` 和 `source.json`。运行时不从 CDN 加载，不增加 npm 构建步骤。

## 采用原则

1. Apache-2.0、MIT 等许可项目可作为明确的候选依赖，但引入前仍固定版本、校验包完整性并保留版权和许可证。
2. GPL、LGPL、AGPL、MPL、EPL、BSL 或混合许可证项目不直接复制到本原型；若未来部署或修改其代码，先由企业法务确认分发、网络服务、插件和闭源模块的义务。
3. 设备协议库只负责采集和标准化，不让 AI 直接写 PLC、PCS、BMS 或安全联锁。当前网关端点是只读观测入口，真实协议适配仍需现场点表、量程、时间同步、证书和回退验证。
4. Demo 设备、台架单片机和正式企业计量使用不同模式。Demo 遥测只能显示和产生提示，不能进入计费、正式方案指纹或真实节省核验。
